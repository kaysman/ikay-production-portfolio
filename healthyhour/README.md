# HealthyHour

*Under Development*

![Cover](images/cover.png)

## Overview

Healthy Hour is a wellness app that helps users maintain a healthy work-life balance by tracking their work and physical activity throughout the day. The app encourages regular movement breaks during work sessions through an intuitive, visually engaging interface.

## Tech Stack

- **Framework:** Flutter (cross-platform iOS/Android)
- **Backend:** Node.js (REST API/GraphQL)
- **Backend Services:** Firebase (Analytics, Crashlytics, Cloud Messaging)
- **Testing:** Firebase App Distribution
- **CI/CD:** GitHub Actions for automated builds and deployments

## Platform

- iOS & Android

## Features

- **Activity Tracking:** Real-time tracking of working and walking sessions with precise duration counters
- **Visual Timeline:** Activity patterns throughout the day with easy toggle between work and walk modes
- **Health Monitoring:** Water intake tracker with circular progress indicators and goal setting
- **Walking Monitor:** Step/duration tracking with daily activity summary and visual progress rings
- **Smart Reminders:** Intelligent prompts to take walking breaks during extended work sessions
- **Customizable Goals:** Activity goals with adjustment options and status indicators
- **Modern UI:** Clean dark/light theme interface with icon-based activity visualization
